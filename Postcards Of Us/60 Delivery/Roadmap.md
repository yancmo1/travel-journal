# Roadmap

## Milestone 0 — Foundation and planning

**Status:** Complete

- [x] Core travel journal application exists.
- [x] Invite-only beta direction documented.
- [x] Production deployment and backup runbooks documented.
- [x] Obsidian project vault created and structured.

## Milestone 1 — Beta readiness

**Status:** Current

**Exit:** [[50 Engineering/Data and Tenant Model#Acceptance checks|Ownership and privacy checks pass]]

- [ ] Verify tenant isolation across all customer-owned records.
- [ ] Verify private photo access and shared journey boundaries.
- [x] Complete and document an isolated staging backup restore drill.
- [ ] Repeat the restore from a scheduled production backup in fresh resources
      and record retention/off-account-copy decisions.
- [ ] Reconcile account lifecycle endpoints.

## Milestone 2 — Invite-only beta learning

- [ ] Onboard a small group of invited families.
- [ ] Track completed journeys and return visits.
- [ ] Record friction and repeated feature requests.
- [ ] Hold a weekly evidence review.
- [ ] Decide which capabilities deserve paid-beta investment.

## Milestone 3 — Paid founding beta

- [ ] Confirm pricing and hosting limits.
- [ ] Harden onboarding, recovery, export, and deletion.
- [ ] Add operational alerts and documented support boundaries.
- [ ] Decide whether social login is justified by beta evidence.

## Milestone 4 — Public product readiness

- [ ] Add selected OAuth providers and account linking.
- [ ] Enable controlled public signup.
- [ ] Complete privacy, recovery, monitoring, and restore gates.
- [ ] Publish support, compatibility, and data-handling expectations.
