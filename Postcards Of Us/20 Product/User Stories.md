# User Stories

## Core loop

- As a family member, I can add a place we visited so the memory has a home.
- As a family member, I can attach photos and a note so the place has a story.
- As a family member, I can group places into a journey so a vacation feels complete.
- As a family member, I can revisit memories by date, person, place, or map.
- As a family member, I can share one journey privately with the people who were there.

## Safety and continuity

- As an invited user, I can sign in without seeing another household's data.
- As an owner, I can recover or export our memories if something goes wrong.
- As a user on a phone, I can complete the core flow without desktop-only controls.

## Later account access

- As an invited user, I can create or access my account through Google, Facebook, or Apple after beta.
- As an existing password user, I can link a social identity without creating a duplicate account.
