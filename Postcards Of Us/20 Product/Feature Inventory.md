# Feature Inventory

## Available now

- Daily memory view
- Memories as the primary records, with journeys for grouping related stops
- Interactive map and routes
- Place and landmark suggestions
- Flexible date precision
- Cleanup mode for duplicates and incomplete details
- Traveler tracking
- Photo resizing, thumbnails, captions, rotation, and ordering
- GPS backfill from photo coordinates
- Search across memories, notes, people, and landmarks
- Timeline and On This Day views
- Printable/downloadable travel books
- Private journey share links
- PWA installation and offline snapshots

## Beta operating features

- Invite-only access
- Personal onboarding and support
- Existing username/password authentication
- Docker deployment with PostgreSQL
- Local photo storage with encrypted backups

## Post-beta candidates

- Social login: Google, Facebook, Apple, and other widely used providers
- Account linking between password and social identities
- Simpler self-service onboarding
- More polished import workflows
- Paid hosting and billing, if beta evidence supports them
