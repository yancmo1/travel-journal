# ADR-003: Use an Obsidian planning layer

## Context

The repository has detailed technical, product, and operational documents, but
they need a connected system for milestones, evidence, decisions, and journals.

## Decision

Use `Postcards Of Us/` as an Obsidian vault modeled on the HomeLab Watcher
project structure. Keep repository documents as linked source material instead
of duplicating them wholesale.

## Consequences

The vault provides navigation and project memory while source files remain close
to the code and deployment runbooks.
